Registrar Acesso

Registro Manual: use para visitantes, prestadores, entregadores autorizados, familiares ou morador sem leitura automática. Para Visitante, Prestador, Entregador Autorizado ou Familiar, informe o RG ou CPF para buscar o cadastro ou um convite válido. Familiar é um visitante que não reside na unidade; Dependente continua no fluxo Morador + Dependente. Se este condomínio exigir documento digitalizado no cadastro de visitantes (Configurações > Sistema > Visitantes), o mesmo anexo também é exigido aqui para liberar o acesso.
